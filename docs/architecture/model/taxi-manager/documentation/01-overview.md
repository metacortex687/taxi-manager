# Обзор Taxi-manager

## Назначение

Taxi-manager — учебная веб-система для управления автомобилями и водителями
автопарка, аутентификации пользователей, геокодирования адресов и зон, а также
хранения точек трека автомобилей.

## Пользователи и внешние системы

- сотрудник автопарка работает с системой через веб-интерфейс React;
- администратор приложения использует Django Admin;
- разработчик изучает OpenAPI-документацию и вызывает REST API;
- внешний клиент телеметрии отправляет точки трека автомобиля;
- LocationIQ выполняет геокодирование по запросу фонового обработчика заданий.

## Архитектурные границы

Основная бизнес-логика реализована в Django. Rust API применяется для операций,
которые по результатам измерений становятся узкими местами по производительности.
Django и Rust API напрямую работают с общей базой данных PostgreSQL/PostGIS,
схема которой управляется миграциями Django.

Наблюдаемость, CI/CD и детали физического развёртывания описываются отдельными
моделями и представлениями, чтобы не перегружать C1- и C2-диаграммы работающего
приложения.
