# Обзор Taxi-manager

## Назначение

Taxi-manager — учебная веб-система для управления автомобилями и водителями
автопарка, аутентификации пользователей, геокодирования адресов и зон, а также
хранения точек трека автомобилей и формирования отчётов.

## Пользователи и внешние системы

- сотрудник автопарка работает с системой через веб-интерфейс React;
- администратор приложения использует Django Admin;
- разработчик внешних сервисов изучает OpenAPI-документацию и вызывает REST API;
- внешний клиент телеметрии отправляет точки трека автомобиля;
- LocationIQ выполняет геокодирование по запросу фонового обработчика заданий.

## Архитектурные границы

Основная бизнес-логика реализована в Синхронном REST API на Django. Контейнер
«Асинхронный REST API и SSE» на Django ASGI обрабатывает асинхронные REST-запросы
и длительные соединения онлайн-отслеживания. Высокопроизводительный асинхронный REST API
реализован на Rust и применяется для операций, которые по результатам измерений
становятся узкими местами по производительности. REST API на Django и Rust
напрямую работают с общей базой данных PostgreSQL/PostGIS, схема которой
управляется миграциями Django.

Сервис уведомлений менеджеров, наблюдаемость, CI/CD и детали физического
развёртывания описываются отдельными моделями и представлениями, чтобы не
перегружать C1- и C2-диаграммы работающего приложения. Специалист сопровождения
и доставка ему email-оповещений показаны только в представлениях наблюдаемости.
